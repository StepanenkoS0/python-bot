# python-bot
# Консольний чат-бот "Організатор подій"

## Мета проєкту

Метою цього проєкту є створення консольного чат-бота на мові Python, який допомагає користувачу організовувати свої події. Бот дозволяє зберігати інформацію про різні події, наприклад лекції, зустрічі, іспити або нагадування. Користувач може додавати нові події, переглядати їх, редагувати або видаляти.

Програма працює у консолі та взаємодіє з користувачем за допомогою текстових команд.

---

## Опис логіки та алгоритму роботи бота

Після запуску програми бот вітає користувача та пропонує ввести команду.
Далі програма працює у безкінечному циклі та очікує введення команд.

Основний алгоритм роботи програми:

1. При запуску програма зчитує події з файлу `events.json`.
2. Бот виводить привітання та пропонує ввести команду.
3. Користувач вводить одну з доступних команд.
4. Програма перевіряє введену команду та виконує відповідну функцію.
5. Якщо користувач додає, редагує або видаляє подію, зміни автоматично зберігаються у файл.
6. Програма працює доти, поки користувач не введе команду **"вийти"**.

---

## Структура даних

Для збереження подій використовується файл **events.json**.
Усі події зберігаються у вигляді списку словників.

Кожна подія містить такі поля:

* **name** — назва події
* **date** — дата події у форматі YYYY-MM-DD
* **time** — час події у форматі HH:MM
* **category** — категорія або короткий опис події

Приклад події у файлі:

```json
{
  "name": "Лекція Python",
  "date": "2026-03-20",
  "time": "10:00",
  "category": "Навчання"
}
```

## Основні команди бота

У програмі реалізовані такі команди:

* **допомога** — показує список усіх доступних команд
* **додати** — дозволяє додати нову подію
* **показати** — показує всі збережені події
* **сьогодні** — показує події на сьогодні
* **завтра** — показує події на завтра
* **тиждень** — показує події на поточний тиждень
* **фільтр** — дозволяє знайти події на конкретну дату
* **редагувати** — змінити інформацію про подію
* **видалити** — видалити подію зі списку
* **вийти** — завершити роботу програми

---

## Інструкція запуску програми

Щоб запустити програму необхідно:

1. Встановити Python на комп’ютер.
2. Завантажити файли проєкту.
3. Відкрити термінал у папці з проєктом.
4. Запустити програму командою:

```
python bot.py
```

Після цього бот запуститься і можна вводити команди.
