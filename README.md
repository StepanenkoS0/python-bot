# Бот-організатор подій

## Мета проєкту
Метою цього проєкту є створення консольного бота-організатора подій на мові програмування Python. Бот дозволяє користувачу створювати, переглядати, редагувати та видаляти події, а також виконувати їх фільтрацію за різними параметрами.

Програма демонструє використання:
- роботи з файлами у форматі JSON;
- структур даних Python;
- обробки текстових команд користувача;
- модуля `datetime` для роботи з датами та часом.

Бот виконує роль простого персонального планувальника подій, який зберігає інформацію між запусками програми.

---

## Концепція роботи бота
Бот працює у консольному режимі. Користувач взаємодіє з програмою шляхом введення текстових команд.

Основні принципи роботи:
- Усі події зберігаються у файлі `events.json`.
- При запуску програми дані автоматично завантажуються у пам’ять.
- Після змін (додавання, редагування або видалення) список подій знову записується у файл.
- Користувач вводить команду, після чого бот викликає відповідну функцію.

Таким чином програма реалізує систему керування подіями з можливістю їх збереження та пошуку.

---

## Логіка та алгоритм роботи бота
Робота програми базується на безперервному циклі обробки команд користувача. Основна функція запускає цикл, у якому бот постійно очікує введення нової команди.

### Загальний алгоритм роботи:
1. Після запуску виконується функція `main()`.
2. Програма завантажує події з файлу `events.json`.  
   Якщо файл відсутній — створюється порожній список подій.
3. Бот виводить привітання.
4. Запускається нескінченний цикл очікування команд.
5. Користувач вводить команду.
6. Команда перевіряється та викликається відповідна функція.
7. Результат виводиться у консоль.
8. Після змін дані зберігаються у JSON-файл.
9. Після команди `вийти` програма завершується.

---

## Алгоритм додавання події
При виконанні команди `додати` бот:
1. Запитує назву події.
2. Запитує дату у форматі `YYYY-MM-DD`.
3. Запитує час початку.
4. Запитує час завершення (необов’язково).
5. Запитує категорію або опис.
6. Перевіряє правильність введених даних.
7. Перевіряє можливий конфлікт у розкладі.
8. Створює об’єкт події.
9. Додає подію до списку.
10. Зберігає зміни у файл.

---

## Алгоритм перегляду подій
Команда `показати`:
- сортує події за датою та часом;
- відображає найближчі події першими;
- виводить список у зручному текстовому форматі.

---

## Алгоритм фільтрації подій
Команда `фільтр` дозволяє обрати спосіб перегляду:
- Події на конкретну дату.
- Події за період між двома датами.
- Події за категорією.

Програма перевіряє всі події та показує лише ті, що відповідають умовам.

---

## Алгоритм нагадувань
Бот використовує поточну дату (`datetime.now()`):
- `сьогодні` — події поточного дня;
- `завтра` — події наступного дня;
- `тиждень` — події протягом 7 днів;
- `найближча` — найближча майбутня подія.

---

## Редагування та видалення подій
1. Виводиться список подій.
2. Користувач обирає номер.
3. Подія редагується або видаляється.
4. Дані автоматично зберігаються у файл.
5. Якщо під час редагування натиснути Enter — значення залишається без змін.

---

## Структура даних
Події зберігаються у файлі `events.json` у форматі JSON як список об’єктів.

### Приклад події
```json
{
  "name": "Іспит",
  "date": "2026-03-15",
  "time": "14:15",
  "end_time": "",
  "category": "коледж"
}
```
